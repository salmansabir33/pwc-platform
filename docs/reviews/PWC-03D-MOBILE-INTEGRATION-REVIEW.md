## Security invariants checked

1. Only the native credential adapter persists access/refresh material, in one versioned encrypted record. No SharedPreferences/plaintext token fallback, browser cookies, URL tokens, telemetry, credential logging, source credentials or committed SDK/cache/signing material. The native marker is a non-secret invalidation generation, never an authentication proof.
2. Refresh is serialized and body-only; old proof is made unrecoverable before sending. Replacement is one coherent record with verification. Failure/timeout/unknown result/reused credentials/identity mismatch/expiry/revocation clears local authority. Backend single-use guards are never weakened. Cold restoration always rotates then validates `me`; no offline login authority or idle heartbeat.
3. Logout clears local state regardless of server acknowledgement; an unavailable server yields a distinct unconfirmed-revocation warning. Failed local deletion locks access. Actor/context/session changes invalidate generations; stale queued/private results cannot attach to another session.
4. Preauth 202 is not authentication. Temporary verification/preauth/enrollment/intent material expires and is not persisted. Personal step-up binds personal user UUID, exact operation, exact session target/object/command. Hold-clear uses its dedicated password/captured-factor request; review-required is not clearable by factor codes. MFA/factor changes never create NGO authority.
5. Organization activation is deliberately unavailable. No request goes to synthetic NGO-private discovery/capabilities/settings/probe APIs. No membership/finance or role inference occurs. Backend negative authorization regressions remain separate from mobile cache/navigation tests; frontend tests are not a substitute for server guards.
6. Full auth transport rejects unknown operations, mixed bearer/public modes, redirects, non-HTTPS/credentialed/query/fragment/path origins, malformed success bodies and unexpected statuses. Protected requests carry a single Bearer header; native public issuance/refresh use no Authorization, Cookie, Origin or Referer.
