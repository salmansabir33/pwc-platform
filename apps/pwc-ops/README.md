# PWC Operations Console — W1 foundation

Independent React/TypeScript/Vite entry point and routes. From the repository root:

```bash
npm ci --ignore-scripts
npm run dev:ops
npm run build -w @pwc/pwc-ops
```

This shell grants no operational authority. No verification, governance, support, finance or NGO-private tools are implemented. No live authentication or API requests. Operational entry and command contracts remain separately gated. No general `isAdmin` or Board-role shortcut exists.

See [W1 runbook](../../docs/runbooks/PWC-W1-WEB-FOUNDATION.md) for tests, configuration and security boundaries.
